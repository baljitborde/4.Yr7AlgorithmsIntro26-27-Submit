🗣️ Command words
  • State – a short answer. No reason needed.
  • Identify – pick out or name something.
  • Write – create your own answer.
  • Explain – say why. Use the word “because”.
  • Describe – say what happens, step by step.
  • Suggest – give a sensible idea of your own.
🔀 Tracing an IF statement
  1. Put the value into the condition.
  2. Is it TRUE or FALSE?
  3. TRUE → run the THEN steps. FALSE → run the ELSE steps (if there is one).
  4. Keep going after ENDIF – there may be more outputs!
⚖️ Operators: check yourself
  • Read the symbol aloud before you answer.
  • Ask: should the boundary value be included or not?
  • With two conditions, ask: do both need to be true, or just one?
  • Test each part of the condition separately, then combine.
🔷 Flowchart shapes key

START Oval = start / end

▭ Rectangle = process

▱ Parallelogram = input / output

◆ Diamond = decision (YES / NO)

📦 Subroutine words
  • Define → Call → Return
  • Think of the recipe card example from your pre-learning.
  • Good names describe what the block does.

Task 3 of 5: Logical operators

⏱️ About 6 minutes  |  4 marks

A school club uses this algorithm.

IF age >= 11 AND age <= 13 THEN
    Output "Join Junior Club"
ELSE
    Output "Not eligible"
ENDIF

3a. State the output when:  (i) age = 12   (ii) age = 14 [2 marks]

An online shop uses a different rule.

IF total > 50 OR member = "Yes" THEN
    Output "Free delivery"
ENDIF

3b. A customer has total = 30 and member = "Yes". Do they get free delivery? Explain your answer. [2 marks]
